# 🎓 教师作业批改助手 (AI Homework Grader)

> AI 驱动的智能作业批改系统，支持多学科、多模型、多格式输入

## ✨ 功能特性

- 📝 **多种输入方式** - 支持手动输入、上传 `.txt` / `.docx` / `.pdf` / `.md` 文件
- 📖 **多学科支持** - 语文、数学、英语、物理、化学、生物、历史、地理、政治、编程等
- 🤖 **多模型选择** - 支持 SiliconFlow、DeepSeek 等多个 AI 服务商
- 📏 **灵活批改标准** - 严格 / 标准 / 宽松三种批改模式
- 📊 **结构化输出** - 评分、详细批改、优点、不足与建议、教师寄语
- 📋 **批改历史** - 自动保存批改记录，随时查看
- 💾 **导出功能** - 支持复制、导出文本、打印批改结果
- 📱 **响应式设计** - 适配桌面和移动端

## 🚀 快速开始

### 1. 安装依赖

```bash
cd homework-grader
pip install -r requirements.txt
```

### 2. 启动服务

**Windows (CMD / PowerShell):**
```bash
python app.py
# 或双击 start.bat
```

**Linux / WSL / macOS:**
```bash
python3 app.py
# 或 chmod +x start.sh && ./start.sh
```

### 3. 访问应用

打开浏览器访问: **http://localhost:5000**

### 4. 配置 API Key

在左侧边栏选择 API 服务商并输入对应的 API Key：

| 服务商 | 获取地址 | 推荐模型 |
|--------|----------|----------|
| SiliconFlow | https://cloud.siliconflow.cn | Qwen2.5-7B (免费) |
| DeepSeek | https://platform.deepseek.com | DeepSeek-V3 |

## 🔧 技术栈

- **后端**: Python + Flask
- **前端**: HTML + CSS + JavaScript (原生，无框架依赖)
- **AI API**: OpenAI 兼容接口 (SiliconFlow / DeepSeek / 自定义)
- **文件解析**: python-docx (Word), PyPDF2 (PDF)

## 📁 项目结构

```
homework-grader/
├── app.py                 # Flask 后端主程序
├── requirements.txt       # Python 依赖
├── README.md             # 项目说明
└── templates/
    └── index.html        # 前端页面 (含完整 CSS/JS)
```

## 📝 使用流程

1. 在左侧边栏选择 **API 服务商** 并输入 **API Key**
2. 选择 **批改模型**（推荐使用免费模型 Qwen2.5-7B）
3. 选择 **课程** 和 **知识点/题型**
4. 选择 **批改标准**（严格 / 标准 / 宽松）
5. 在右侧输入或上传 **作业内容**
6. 点击右上角 **「开始批改」** 按钮
7. 等待 AI 批改完成，查看结果

## ⚠️ 注意事项

- API Key 仅存储在浏览器本地 (localStorage)，不会上传到服务器
- 批改结果仅供参考，最终评分请以教师判断为准
- 建议使用免费模型进行测试，正式使用时可选择更强大的付费模型
