一、产品概述

教师作业批改助手是一款基于大语言模型（LLM）的智能作业批改系统。教师只需输入学生作业内容、选择学科，AI 即可自动完成评分、逐题批改、优点分析、改进建议及教师寄语，大幅提升批改效率。

本产品支持 11 门学科、3 家 AI 服务商（DeepSeek、Kimi 月之暗面、SiliconFlow 硅基流动），可手动输入文字或上传文件（.txt / .docx / .pdf / .md），并提供严格、标准、宽松三种批改尺度。

三、快速上手（5 步完成批改）

步骤 1：获取 API Key

在使用批改功能前，需要先获取 AI 服务商的 API Key（三选一即可）：

服务商获取地址免费额度推荐模型
DeepSeek 官方platform.deepseek.com新用户注册即送DeepSeek-V3（综合最强）
Moonshot Kimiplatform.moonshot.cn注册送 15 元体验金Kimi K2.5（256K 上下文）
SiliconFlow 硅基流动cloud.siliconflow.cn免费模型可用Qwen3-8B（免费）

步骤 2：打开公网链接

在浏览器中打开上方提供的公网链接，看到左侧配置面板 + 右侧作业输入区的界面。

步骤 3：配置 API

1

在左侧"API 服务商"下拉框中选择你注册的服务商。注意：DeepSeek 的 Key 只能选"DeepSeek 官方"，不可与其他服务商混用。

2

在"API Key"输入框中粘贴你的 Key。（直接登录的界面已经内置好本人的 API，可以直接使用）

3

在"批改模型"中选择模型。

步骤 4：输入作业并开始批改

1

在左侧"选择课程"中点击目标学科（如数学）。

2

选择知识点/题型，以及批改标准（严格 / 标准 / 宽松）。

3

在右侧输入框中粘贴作业内容，或切换到"上传文件"页签上传文档（文档上传后，其内容会自动解析显示在正下方）。

4

点击右上角"开始批改"按钮。

5

等待 10-30 秒，右侧将显示 AI 生成的结构化批改结果并将此次分析记录在左侧栏下方的"批改记录"中。

步骤 5：查看与导出结果

批改结果包含：评分 - 总体评价 - 详细批改 - 优点 - 不足与建议 - 教师寄语。

结果区上方有"重置"按钮，会重置所有配置选项和上传的文本或文件；下方提供三个操作按钮：复制结果（一键复制到剪贴板）、导出文本（下载为 .txt 文件）、打印（直接打印或保存为 PDF），以及此次解答的基本信息（科目、使用的模型、时间、解析字数等）。

六、常见问题 (FAQ)

Q1: 提示"API 调用失败: Api key is invalid"？

A: 最常见的原因：服务商和 API Key 不匹配。DeepSeek 的 Key 只能选"DeepSeek 官方"，SiliconFlow 的 Key 只能选"SiliconFlow"，Kimi 的 Key 只能选"Moonshot (Kimi 月之暗面)"。请检查左侧是否选对了服务商。

Q2: 提示"temperature: only 1 is allowed for this model"？

A: 某些推理模型（如 DeepSeek-R1、Kimi K2.5）只接受 temperature=1。切换到 DeepSeek-V3 或 Moonshot V1 等普通模型即可，系统已自动适配该参数。

Q3: 左侧课程按钮点不了、科目全部消失了？

A: 通常是页面 JavaScript 加载异常。按 Ctrl+F5 强制刷新浏览器即可恢复。

Q4: 批改结果中出现大量数学符号（如 $ \frac \Delta 等）？

A: AI 有时会使用 LaTeX 数学格式。系统已优化提示词要求纯文本输出。如偶有出现，重新批改一次即可消除。

Q5: 上传文件后在哪里查看文件内容？

A: 文件上传成功后，输入框下方会自动出现"文件内容预览"区域，展示解析出的完整文本，超出可滚动查看。

Q6: 支持什么文件格式？

A: 支持 .txt、.docx、.pdf、.md 四种格式，推荐 .txt 和 .docx 效果最佳。

Q7: API Key 安全吗？

A: 安全。Key 仅存浏览器本地（localStorage），直连 AI 服务商，不经过服务器记录或转发。

Q8: 可以免费使用吗？

A: 可以。DeepSeek 新用户送额度、Kimi 注册送 15 元、SiliconFlow 有免费模型。

Q9: 公网链接打不开怎么办？

A: 链接部署在 Railway 云服务器，永久有效，无需梯子。如无法访问请检查网络或联系管理员，推荐 Chrome / Edge 浏览器。

Q10: Kimi 模型批改太慢？

A: 建议单题用 DeepSeek-V3 或 Moonshot V1-8K（更快），长篇作业再用 Kimi K2.5（256K 上下文优势）。系统已将输出限制为 2048 tokens。

Q11: 批改结果准确吗？

A: AI 批改仅供参考，最终评分请以教师判断为准。建议 AI 初筛后，教师重点复核 AI 标记的错误项和改进项。

八、测试样例

样例 1：数学 - 代数（含错误）

[题目] 解方程 2x² - 5x - 3 = 0

[学生解答] 使用求根公式，a=2, b=-5, c=-3，判别式 = 25+24 = 49，x1 = 3，x2 = 0.5

提示：x2 应为 -0.5（符号错误），可测试 AI 能否发现。

样例 2：地理 - 自然地理（含错误，三种评判标准下有不同评分）

[题目] 分析我国南方地区和北方地区的自然地理环境差异。

[学生解答]

南方和北方以秦岭-淮河为界，差异挺大的。

气候：南方热，北方冷。南方下雨多，北方下雨少。

地形：南方多山，北方多平原。

农业：南方种水稻，北方种小麦。

河流：南方河流多，北方河流少。

总的来说，造成这些差异的原因是纬度不同。

提示：内容不完整、表达口语化、遗漏重要维度，分别用严格/标准/宽松批改可看到明显差异。

样例 3：语文 - 作文片段

[题目] 以"我的老师"为题写一段话。

[学生习作] 我的老师十分和蔼，她有一头乌黑的头发，脸上总挂着微笑。上课时她认真讲解每一个知识，下课后她耐心解答我们的问题。

提示：可测试 AI 对写作的点评能力。
