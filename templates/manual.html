一、产品概述

教师作业批改助手是一款基于大语言模型（LLM）的智能作业批改系统。教师输入学生作业内容、选择学科，AI 即可自动完成评分、逐题批改、优点分析、改进建议及教师寄语，大幅提升批改效率。

三、功能操作详细说明

步骤一：配置 API

1

在左侧边栏 「🤖 API 服务商」 中选择：

  • DeepSeek 官方：使用 DeepSeek 官方 API（推荐）
  • SiliconFlow (硅基流动)：国内可用，免费模型

在 「🔑 API Key」 中输入你的 API Key：

服务商获取地址
DeepSeekplatform.deepseek.com（注册送额度）
SiliconFlowcloud.siliconflow.cn（免费模型）

步骤二：选择课程与模型

2

在左侧选择 学科（10+ 学科可选），再选 模型：

  • DeepSeek-V3：综合能力最强（推荐）
  • DeepSeek-R1：深度推理，适合数学
  • Qwen3-8B：免费可用

步骤三：输入作业内容

3

支持两种方式：

  • 手动输入：在文本框粘贴作业内容
  • 上传文件：点击或拖拽上传（支持 .txt .docx .pdf .md）

步骤四：选择批改标准并开始

4

选择批改标准（严格/标准/宽松），点击右上角 「✨ 开始批改」。

等待 10-30 秒，AI 返回结构化批改结果：评分、总体评价、逐题批改、优点、不足与建议、教师寄语。

步骤五：导出结果

批改完成后可以：📋 复制结果 · 💾 下载 TXT · 🖨 打印

五、常见问题

Q1: 提示"API 调用失败: Api key is invalid"？

A: 最常见的原因——服务商和 API Key 不匹配。DeepSeek 的 Key 只能选「DeepSeek 官方」，SiliconFlow 的 Key 只能选「SiliconFlow」。

Q2: 提示"temperature: only 1 is allowed"？

A: 推理模型（DeepSeek-R1、Kimi K2.5）限制 temperature=1。切换到 DeepSeek-V3 或 Moonshot V1 等普通模型即可，系统已自动适配。

Q3: 左侧按钮点不了、科目消失了？

A: 通常是页面 JS 加载异常。按 Ctrl+F5 强制刷新浏览器即可恢复。

Q4: 结果中出现 $ \frac \Delta 等符号？

A: 系统已优化提示词要求 AI 用纯文本输出。如偶有出现，重新批改一次即可消除。

Q5: 上传文件后在哪查看内容？

A: 输入框下方会自动出现「📄 文件内容预览」区域，完整展示解析文本，支持滚动查看。

Q6: 支持什么文件格式？

A: .txt / .docx / .pdf / .md，推荐 .txt 和 .docx 效果最佳。

Q7: API Key 安全吗？

A: 安全。Key 仅存浏览器本地（localStorage），直连 AI 服务商，不经过服务器。

Q8: 可以免费使用吗？

A: 三家均可免费上手：DeepSeek 新用户送额度、Kimi 注册送 15 元、SiliconFlow 有免费模型。

Q9: 公网链接打不开？

A: 链接基于 Cloudflare Tunnel，如服务端重启会导致地址变更。请联系管理员获取最新链接，推荐 Chrome/Edge 浏览器。

Q10: Kimi 模型太慢？

A: 单题批改选 DeepSeek-V3 或 Moonshot V1-8K 更快；长篇作业再用 Kimi K2.5 发挥其 256K 长上下文优势。
